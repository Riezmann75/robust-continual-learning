# Corrected mixing results, seed 17

See the [main README](../../README.md#corrected-mixing-comparison-seed-17) for the comparison and limitations. Each run directory contains the full per-corruption/severity evaluation, original configuration, completion record, epoch summary, and source snapshot verified against configuration SHA256 hashes. Local absolute paths inside original configurations are retained as provenance; use --data-root when reproducing elsewhere. No checkpoint, dataset or batch trace is published. comparison.json includes the aggregate sampling fingerprint verified across all 15,650 updates of the four fingerprinted runs, including the subsequent InfoNCE/JS ablation.

The archive also contains three chain-aware fixed-m variants: InfoNCE / JS in `chain_aware_fixed_m`, JS / JS in `chain_aware_js`, and InfoNCE / InfoNCE in `chain_aware_infonce_infonce`. [Class-IL and Task-IL category/per-corruption tables](../../docs/corruption_category_results.md) cover all eight runs. corruption_categories.json provides the unrounded aggregate values. The sampling-equality claim applies only to the four listed fingerprinted runs in comparison.json, not the chain-aware variants.
